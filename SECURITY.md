# Security policy

Report vulnerabilities privately through GitHub: Security tab → Report a vulnerability.

- Do not open a public issue for a vulnerability.
- Expect a first reply within 7 days.
- Supported version: latest `main` and latest `latest` image.

In scope: auth handling, the nginx proxy config, the Docker image.
Out of scope: exposing the Palworld REST API to the internet (see README → Security).
